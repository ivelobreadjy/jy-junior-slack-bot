jy junior slack bot

A 24/7 Slack bot built with Node.js, running on Hack Club Nest.

About

jy junior is a Slack bot that responds to greetings and a growing set of slash commands, from quick utilities to extras and live data from public APIs. Built for the Stardance Challenge as a first dive into backend development, Slack APIs, and 24/7 hosting on a Linux server.

Commands

  • /jy-junior-pingCheck the bot's latency
  • /jy-junior-helpList all available commands
  • /jy-junior-catfactGet a random cat fact
  • /jy-junior-jokeGet a random joke
  • /jy-junior-8ballAsk the magic 8-ball a question
  • /jy-junior-rollRoll a dice (optionally specify sides)
  • /jy-junior-adviceGet a random piece of advice
  • /jy-junior-quoteGet a random inspirational quote
  • /jy-junior-apodNASA Astronomy Picture of the Day

The bot also replies to friendly messages like "hi, "hello", and "who are you?"

Try it

Want to see it in action? Join the Hack Club Slack, head to any channel the bot is in (like #bot-spam), and type /jy-junior-help to see everything it can do.
